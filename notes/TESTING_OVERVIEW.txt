📊 KEY METRICS
═══════════════════════════════════════════════════════════════════════════

OVERALL PRECISION (Target: ≥75%)
├─ Positive feedback ratio
├─ Watch-through rate (≥40%)
└─ User rating of watched films (≥3.5/5)

BY FEATURE (Per-source precision)
├─ Streaming filter:  Target ≥70%
├─ Home rows:         Target ≥65%
├─ Mood scan:         Target ≥60%
└─ Search results:    Target ≥70%

BY GENRE (No genre <50%)
├─ Comedy, Drama, Action, Sci-Fi, Horror, etc.
└─ Problem genres trigger root-cause analysis

ENGAGEMENT
├─ Active beta testers
├─ Average feedback per user
├─ Problem films identified
└─ Time to actionable insights


✅ SUCCESS CRITERIA FOR LAUNCH
═══════════════════════════════════════════════════════════════════════════

MUST BE YES:
  [✓] Overall precision ≥75%
  [✓] All major genres ≥50% (most ≥60%)
  [✓] Streaming filter ≥70%
  [✓] Home rows ≥65%
  [✓] Mood scan ≥60%
  [✓] Watch-through rate ≥40%
  [✓] Average rating of watched films ≥3.5/5
  [✓] <5% complaints in weekly surveys
  [✓] No critical bugs
  [✓] Performance <500ms per recommendation

If any criteria is NO → Fix it, re-test, then launch.


🔧 COMMON FIXES (From FEEDBACK_ANALYSIS_COOKBOOK.md)
═══════════════════════════════════════════════════════════════════════════

Issue: Low precision for Genre X
├─ Diagnosis: Not enough same-genre neighbors
└─ Fix: Increase genre_match weight in scoring
   python export_for_app.py --rebuild

Issue: Mood scan underperforming
├─ Diagnosis: Too few films in that mood category
└─ Fix: Add more films to MOOD_MAPPING
   python export_for_app.py --rebuild

Issue: Age rating filter is too restrictive
├─ Diagnosis: Narrow combination of mood + age = few options
└─ Fix: Use content analysis instead of genre alone
   python export_for_app.py --rebuild

💡 TIPS
═══════════════════════════════════════════════════════════════════════════

• Start with manual validation (100 films) BEFORE collecting feedback
• Use weekly_checks.py automation to stay on top of metrics
• Keep feedback simple: just 3 buttons + basic metadata
• Don't rebuild model every day; batch improvements
• A/B test improvements (v2.0 vs v2.1) before full deployment
• Document what you change in export_for_app.py for reproducibility
• Save feedback.db backups weekly
• Create monthly trend reports (4-week rolling average)
