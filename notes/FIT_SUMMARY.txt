RISKS & MITIGATIONS
================================================================================

RISK LEVEL: 🟢 LOW (No critical blockers)

Potential Issues:

1. TMDB ID Coverage
   Risk: 🟡 If <80% of films have TMDB ID mapping
   Impact: App can't fetch posters/streams from TMDB
   Mitigation: Use TMDB search API to fill gaps (automated)
   Probability: 🟢 Low (Letterboxd well-integrated with TMDB)
   Action: Check ml_prompt_tmdb_id.md immediately

2. Tag/Mood Vocabulary
   Risk: 🟡 If tags too generic or inconsistent
   Impact: Home rows don't meaningfully group films
   Mitigation: Pre-filter to 50–100 tags; test clustering
   Probability: 🟢 Low (easy to fix if needed)
   Action: Define vocabulary in next 30-min call with Peter

3. Age Rating Data
   Risk: 🟡 If TMDB missing ratings for 10%+ films
   Impact: "Family" filter less useful for some films
   Mitigation: Fallback to "no restriction"; document gaps
   Probability: 🟢 Low (acceptable fallback exists)
   Action: Plan TMDB fetch + fallback before export
